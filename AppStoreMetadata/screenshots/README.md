# App Store Screenshots

Capture these on an Apple TV 4K (or the tvOS simulator at 4K) before upload.

## Required sizes

| Display | Resolution | Notes |
|---|---|---|
| Apple TV | 1920 × 1080 | Required baseline |
| Apple TV | 3840 × 2160 | Optional high-resolution variant |

## Required shots

1. Home with Continue Watching and Recently Added shelves.
2. Library grid with quality badges (4K, Dolby Vision, Dolby Atmos).
3. Movie detail with cast, tracks, and playback quality.
4. Player overlay with chapters, audio, and subtitle menus.
5. Pipeline detail sheet explaining the selected rung.
6. Settings with source management and About This Apple TV.

## Naming

Use `playitright-<screen>-<resolution>.png`, for example:

- `playitright-home-1920x1080.png`
- `playitright-library-3840x2160.png`

Do not include private source names, server addresses, credentials, or personal
media titles in screenshots. Use the sample library.
